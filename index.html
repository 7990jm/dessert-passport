About this channel

Dessert Passport is a YouTube Shorts channel about desserts from around the world. Every episode visits one country and one dessert, and collects one more stamp.

Dessert Passport Uploader

The Dessert Passport Uploader is a private tool used only by the owner of this channel. It uploads the channel's own finished videos to YouTube through the YouTube Data API, together with their titles, descriptions, tags, subtitle files and thumbnails, and can schedule when they become public. It is not offered to the public and no other users sign in to it.

Privacy Policy

Last updated: October 6, 2026

  1. What the tool accesses. With the channel owner's permission (Google OAuth), the tool uses only the YouTube Data API scopes needed to upload videos, captions and thumbnails to the owner's own channel. It does not read, collect or store data about viewers or any other YouTube users.
  2. Storage. The sign-in token is stored only on the owner's own computer. Nothing is sent to any server other than Google's YouTube services.
  3. Sharing. No data is sold, shared or transferred to third parties.
  4. Revoking access. Access can be removed at any time at myaccount.google.com/permissions.
  5. YouTube API Services. This tool uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. See also the Google Privacy Policy.
